# 📚 学习计划

一个为自己定制的轻量学习时间规划 App(PWA)。

自己安排每天的学习和休息时间——比如上午 9 点到 10 点学习,然后休息 20 分钟——到点自动弹窗提醒。学习多久、休息多久,全部由你自己决定。

## ✨ 功能

- **自由时间块**:任意添加"学习"或"休息"时间块,自定义开始时间和时长;连续排计划时,开始时间自动衔接上一块的结束时间
- **今日总览**:自动统计今天规划的学习总时长、休息总时长和时间块数量
- **到点提醒**:到学习时间、休息时间、学习结束时弹出提示(带提示音 + 系统通知)
- **状态一目了然**:进行中的时间块高亮显示,已过去的自动变淡
- **每日重置**:以凌晨 4 点为数据日分界,每天自动清空全部数据和记录,从零开始规划新的一天
- **离线可用**:数据只保存在自己的设备上,不依赖账号和服务器,没网也能打开

## 📱 使用方式

1. 把本项目部署到任意 HTTPS 静态托管(如 GitHub Pages)
2. iPhone 用 Safari 打开网址 → 分享 → **添加到主屏幕**
3. 首次打开时点击"🔔 开启提醒"授权通知,即可像普通 App 一样使用

> 提示:网页应用的通知需要在 App 处于打开状态(含后台挂起)时才能送达,建议使用时保持 App 开着。

## 🛠 技术栈

纯原生 HTML + CSS + JavaScript,无框架、无构建工具、无后端。数据存储于浏览器 localStorage,通过 Service Worker 实现离线缓存。
